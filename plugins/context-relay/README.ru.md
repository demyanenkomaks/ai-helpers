# context-relay

Погода контекста, подогрев кэша промпта и передача беседы в новый чат одной
кнопкой. Один мод Claude Code, один ряд пилюль над промптом (вид следует
Token Weather Usage от augiefra):

```
⛈ 362k ▁▃█ +5k ⇄ │ ≈ $1.84 +$0.12 │ ⚡ кэш 41m 1/4 ↻ │ 👥 1/3 ▾
```

| Пилюля | Что показывает | Карточка по наведению (десктоп) / ▾ (терминал) |
| --- | --- | --- |
| Погода | токены в контексте; цвет полосы несёт только иконка: ☀ до 100k, ☁ до 250k, 🌧 до 350k, ⛈ выше; бары это последние ходы, ▲ цена последнего; ⇄ в конце это кнопка передачи, яркая с «Дождя» | полоса, окно, последние ходы |
| ≈ $ | стоимость сессии и доля последнего запроса | то же |
| ⚡ кэш | минуты до остывания кэша, доля попаданий если ниже 90%, использованные пинги подогрева; ↻ подогревает сейчас | состояние кэша, доля, пинги и их цена |
| 👥 | субагенты: работает / всего, красным пока кто-то работает | каждый с типом и длительностью |

## Передача

Нажмите ⇄ (или введите `/relay`). Мод просит модель поверх кэшированного
транскрипта написать сводку по форме `templates/handoff.md` (цель, состояние,
решения, файлы, следующий шаг, подводные камни), записывает её в
`~/.claude/context-relay/handoff/<проект>/<дата-время>.md`, очищает чат и
подкладывает сводку в первое сообщение новой беседы.

Очистка пробуется тремя способами по очереди, каждый проверяется по id сессии
и числу ходов: команда `/clear`, запущенная модом; та же строка, отправленная
как промпт; и, если не сработало ни то, ни другое, собственное сжатие мода, на
которое он отвечает одной сводкой, так что контекст становится сводкой на
месте. Если не удались все три, полоса показывает причину словами движка
красным до вашего следующего сообщения, а сводка остаётся взведённой:
загрузится с первым сообщением после того, как вы очистите чат сами. Файл
удаляется после доставки.

Если вместо этого вы откроете новую сессию руками, полоса покажет
**Загрузить** и **Убрать** для сводки моложе 7 дней.

Автоматика: когда после хода контекст достигает 500k токенов, под полосой в
чате, над полем ввода, появляется вопрос: что сейчас произойдёт, сколько секунд
осталось, и кнопки **Да** / **Нет**. **Да** или 30 секунд молчания собирают
сводку, очищают чат и подкладывают её в новый. **Нет** оставляет текущий чат
как есть до следующего пересечения порога.

## Настройки

В `/config` (или в настройках плагина в десктоп-приложении):

| Настройка | По умолчанию | Смысл |
| --- | --- | --- |
| Keep the prompt cache warm | `4h` | `off`, `2h`, `4h` или `8h` пингов при простое |
| Automatic handoff at | `500000` | токены; `0` выключает |
| Countdown before an automatic clear | `30` | секунды, пока ждёт вопрос Да / Нет |
| Weather band boundaries | `100000,250000,350000` | три возрастающих числа |
| Handoff folder | пусто | пусто означает `~/.claude/context-relay/handoff` |

Подписи следуют языку системы на десктопе (русский или английский: на
Windows это культура, которую сообщает PowerShell, иначе `LANG`) и английские
в терминале.

## Стоимость

Пинг подогрева это один запрос, отвечаемый из кэша промпта: он читает весь
контекст по тарифу чтения кэша и расходует пятичасовой лимит. Карточка
деталей показывает, сколько пингов ушло за текущий простой.

## Установка

```
/plugin marketplace add demyanenkomaks/ai-helpers
/plugin install context-relay@ai-helpers
```

Нужна сборка Claude Code с function hooks (2.1.287 или новее).

## Разработка

```
claude plugin validate plugins/context-relay
claude plugin test plugins/context-relay
```

Модуль хуков это `hooks/register.tsx`; всё, что касается `$`, живёт там,
потому что движок прослеживает `$` только внутри одного файла. Чистые
помощники в `bands.ts`, `handoff.ts`, `warm.ts`, `i18n.ts`, `icons.ts`,
`log.ts`, деревья в `draw.ts`. Дизайн в `docs/context-relay-design.ru.md`.

Мод записывает, что он видел от движка, в
`~/.claude/context-relay/context-relay.log` (64 КБ, старые строки
отбрасываются): начало и конец сессии, показания на старте, каждый шаг
передачи с результатом, сжатия. Приложите его к сообщению об ошибке.

## Истоки

Погодные полосы, показания и бары последних ходов следуют примеру Anthropic
`token-weather` (claude-code-playground, Apache-2.0). Таймер кэша, стоимость и субагенты следуют `token-weather-usage` от augiefra (Apache-2.0).
Код здесь написан заново под API этой сборки.
