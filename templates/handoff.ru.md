# Формат сводки для передачи контекста

Структура сводки: записки, которую мод `context-relay` просит модель
написать перед очисткой чата, и которую человек пишет сам, когда переносит
работу в новую сессию. Собственная копия промпта у мода лежит в
`plugins/context-relay/assets/handoff-prompt.md`; держите их согласованными.

```markdown
# Handoff

## Goal
Чего человек добивается, одно-два предложения.

## Current state
Сделано и проверено / сделано, но не проверено / наполовину. Ветка и есть ли
незакоммиченные изменения.

## Decisions made
По одному пункту на решение, с причиной.

## Files changed or important
Пути, по строке на каждый.

## Open tasks and next step
По порядку; самый первый шаг настолько точный, чтобы начать сразу.

## Gotchas
Ловушки, неудачные подходы, особенности окружения. «None noted», если нет.
```

Правила, которые делают сводку полезной:

- Описывать состояние работы, а не ход разговора.
- Называть вещи: файлы, команды, числа, имена веток.
- Писать на том языке, на котором обсуждалась работа.
