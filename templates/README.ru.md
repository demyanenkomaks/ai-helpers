# templates/

Файлы, которые плагины копируют В проект (сам плагин не может положить правила
в проект). Типичное содержимое:

- `laravel/CLAUDE.md`: стартовый CLAUDE.md для проекта на Laravel/Filament
- `laravel/rules/*.md`: файлы для `.claude/rules/` проекта
- `handoff.md`: формат файла передачи контекста между сессиями

Слэш-команда владеющего плагина (например `/laravel-init`) копирует нужную
папку в текущий проект. Шаблоны держите маленькими и общими: знание о
конкретном проекте живёт в проекте, а не здесь.
